03 / SCHOOL SUBMISSION

The AI project cycle.

The project is organised around the exact deliverables in the school brief. Complete the empathy study and user testing with real observations before submission.

01

Problem statement

Students and households may be unsure how to sort common waste. Incorrect sorting can contaminate recyclables or send special waste into ordinary bins.

DEFINE THE PROBLEM
02

User / empathy study

Planned method: ask 5–10 students or family members how they currently sort waste. Ask which items confuse them and what kind of help they would use. Record actual answers.

LISTEN BEFORE DESIGNING
03

Brainstorming

Ideas considered: illustrated bin poster, quiz cards, searchable waste guide, and a simple website that classifies an item and explains why.

COMPARE SOLUTIONS
04

Solution design

Choose an item → classify it → show category, reason and disposal tip. Keep language short, provide a special-waste warning and remind users to check local rules.

PLAN THE USER FLOW
05

Data details

Prototype data contains example items, suggested categories, explanations and tips. In a full study, record item, material, contamination, local rule source and verification date.

LABELS MUST BE VERIFIED
06

Prototype & modelling

This version uses a transparent rule-based lookup table. It demonstrates classification logic; it is not a trained machine-learning model and does not use a camera.

BUILD A BASELINE
07

Testing & feedback

Test each listed item, check the output and ask users if it is clear. The checklist below is for recording results; do not claim tests were completed until you run them.

MEASURE, THEN IMPROVE
08

Reflection

Strength: simple and explainable. Limits: small example set, no location-specific rules and no visual recognition. Next: verify data with local authorities and improve using user feedback.

BE HONEST ABOUT LIMITS
