# EcoSort AI 🌱

A Grade 9 Artificial Intelligence project prototype that helps users learn how to sort everyday waste more responsibly.

![EcoSort AI logo](logo.svg)

## Features
- Responsive educational website.
- Interactive waste-item classifier using a transparent, rule-based lookup table.
- Animated cosmic particle background that responds to mouse movement.
- Original SVG logo and favicon.
- AI project-cycle documentation, test checklist, and video-pitch outline.

## Run locally
This is a static website; no package installation or build step is needed.

1. Download or clone this repository.
2. Open `index.html` in a browser, or start a local server from this folder:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Files
- `index.html` — page content
- `style.css` — responsive design and animation styles
- `app.js` — educational waste classification rules
- `background.js` — animated particle spiral and pointer parallax
- `logo.svg`, `favicon.svg` — brand assets

## Important limitation
The current classifier is a predefined rule-based prototype, not a trained machine-learning model. It does not use a camera, live data, or location-specific municipal rules. Always verify disposal guidance with local authorities. The empathy study and user testing must be completed with real participants before being reported as completed.

Problem statement · user/empathy study · brainstorming · solution design · data details · prototype · testing and feedback · reflections · video pitch.
